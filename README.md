# HPL Schools® — Partnerships & Franchising

English-language landing page for property developers and investment partners, presenting a school franchise with HPL operational management.

## GitHub Pages

1. Upload the contents of this package to the root of your repository.
2. Open Settings → Pages.
3. Select Deploy from a branch → main → /(root) → Save.

No installation or build is required. The page uses relative paths and supports repository subpaths. No custom domain is configured.

## Preview

Run `python3 -m http.server 8080` in this folder, then open http://localhost:8080.

## Features

Responsive design, five nature-inspired concepts, a readable curriculum overview, People / Planet / Life / Play themes, T4HPL learning principles, educational materials, interactive Learning Labs and expandable FAQs.

The enquiry form prepares an English email to olimpia@olimpiamesa.com in the visitor’s email app. The visitor sends it from there. No data is stored by this static website.

Poppins loads from Google Fonts, with an Arial fallback. Images are local. Rights to HPL branding and artwork remain with their owners.

## Partnership content

Capital recovery and subsequent 50/50 profit sharing are presented as an indicative proposal, subject to financial, legal and feasibility review. No guaranteed returns, fixed opening dates or active certification are promised.

The project is prepared for GitHub Pages and has not yet been uploaded to a GitHub repository.
